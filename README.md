# Football Legends AI

MVP production project for the fictional match AC Milan 2005/06 versus Manchester City 2022/23.

## Current MVP

- 9:16 vertical short
- Fictional AI recreation, not authentic archive footage
- Main players: Maldini, Nesta, Stam, Pirlo, Kaká, Shevchenko, Haaland, Bernardo Silva, De Bruyne and Rodri
- Referee: Pierluigi Collina
- Key beats: stadium opening, physical Haaland duels, Shevchenko goal, no-VAR protest, Haaland goal, mysterious Zidane reveal
- Final score intentionally undisclosed

## Workflow

1. Script
2. Shotlist
3. Storyboard
4. Animatic
5. Keyframes and references
6. AI video generation
7. Edit and sound design
8. Quality control and export

See `project/` for production documents and `rights/` for source tracking.
