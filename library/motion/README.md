# Motion Library

This library stores reusable motion-analysis and 3D animation assets.

## Pipeline

`raw-video` → `pose-estimation` → `reconstructed-3d` → `blender-corrections` → `fbx` → `motion-matching` → `ball-interactions`

Keep previews and technical metadata with each motion asset. Record source, performer, reconstruction method, corrections, frame rate, skeleton/rig and usage rights.
